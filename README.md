# Text-to-Image-Generator
🎨 **AI Image Generator** is a web application that transforms text prompts into AI-generated images. Built using HTML, CSS, and JavaScript, it features a responsive user interface, dark/light theme toggle, random prompt suggestions, and image downloads. Integrated with the Hugging Face Inference API for AI-powered image generation.
Project-Link :- https://text-to-ai-image-generator.netlify.app/
